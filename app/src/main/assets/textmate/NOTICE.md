# TextMate grammars

Bundled for syntax highlighting in GCode's code editor (Sora Editor). Taken unmodified from:

| Grammar | Source | Licence |
|---|---|---|
| Kotlin | github.com/fwcd/vscode-kotlin (syntaxes/kotlin.tmLanguage.json) | MIT |
| Java, JSON, XML, YAML, Markdown, Shell, Python, Groovy | github.com/microsoft/vscode (extensions/*/syntaxes) | MIT (each file names its upstream project in `information_for_contributors`) |

`gcode-dark.json` and `gcode-light.json` are GCode's own themes (Apache-2.0).
